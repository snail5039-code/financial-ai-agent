# 금융 AI 투자 운영 대시보드 목업

`MOCKUP-001-I` 대시보드와 `MOCKUP-002-I` 삼성전자 기업 상세 화면으로 구성된 1440×900 정적 프론트엔드입니다. 모든 수치는 화면 검토용 고정 예시이며 외부 API, 데이터베이스, 인증, 계좌 또는 주문 시스템과 연결되지 않습니다.

## 실행

패키지 설치 없이 Python 표준 라이브러리로 실행합니다.

```powershell
python -m http.server 4173
```

작업공간 루트에서 실행한 다음 `http://127.0.0.1:4173/mockup/financial-dashboard/`을 엽니다. `index.html`을 직접 열어도 모든 기능이 동작합니다.

## 포함된 상호작용

- 자산 차트 위 마우스 이동 또는 이벤트 점 키보드 포커스 시 툴팁
- 첫 번째 핵심 근거 접기/펼치기
- 반려 상태 변경 후 두 결정 버튼 비활성화
- 모의승인 상태 변경 후 두 결정 버튼 비활성화
- 판단 무효 조건 3개를 키보드 또는 마우스로 펼치고, 필요한 경우 인스펙터 본문을 세로 스크롤해 확인
- 대시보드 삼성전자 행 또는 종목명으로 기업 상세 진입, 상세 헤더와 인스펙터 하단에서 복귀
- 상세 화면의 긍정·반대 근거 6개 및 예시 공시 3개 선택 시 검증 인스펙터 갱신
- 상세 가격 차트 포인트 hover 또는 키보드 포커스 시 가격 툴팁
- 승인 대기 목록의 4개 가상 주문 필터·선택·독립 반려·모의승인과 주문 상세 확인
- 에이전트 실행 기록의 결정·단계·출처 선택과 최초 제안/검증 후 결과 비교
- 투자 정책 설정의 범위 검증, 충돌 경고, DEC-1042 가상 적용 미리보기
- 주간 투자 리포트의 기간 선택, 수익률 막대·행·위험 항목 선택, 인스펙터 갱신
- 데이터 연결 상태의 연결 대상 선택, 상태 필터, 화면용 연결 점검 결과 갱신

## 안전 범위

- 네트워크 요청 코드 없음
- 실제 금융 데이터 및 공시 미연결
- 실제 주문 또는 계좌 연동 없음
- 모의승인 처리는 현재 브라우저 화면 상태만 변경
