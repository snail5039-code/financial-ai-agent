## 현재 상태 메모

- 공식 역할 작업은 사용자가 사이드바에서 확인할 수 있는 별도 Codex 작업으로 운영한다.
- 공식 역할 세대교체 또는 신규 배정은 `create_thread`로 보이는 작업을 생성한다.
- 숨은 multi-agent 하위 에이전트는 공식 기획자·구현자·검증자를 대체할 수 없으며, 사용자가 명시 허용한 임시 보조 조사에만 제한한다.
- `FRONTEND-005`는 `b654282 승인 대기 행 접근성 구조 정리`로 완료·검증·커밋·푸시됐다.

## 이전 세대 참고

- 관리자 6세대와 기획자 6세대 전환 과정 이후 관리자 7세대가 현재 지휘를 맡는다.
- 관리자 4세대 `01a03de8-57ef-74a1-a210-654946be36a9`는 `MOCKUP-014` 완료와 분할 문서 생성 후 5세대로 세대교체했다.
- 기획자 4세대 `01a03de8-b822-7d12-a30e-f68f9524052f`, 구현자 4세대 `01a03de8-b85c-7661-81f4-d8df32e79365`는 이전 세대로 남긴다.
- 검증자 7세대 `01a03de8-b89e-7871-90b7-4763bc33ecd5`는 `MOCKUP-014` R1/R2 재보고가 빈 결과로 끝나 8세대로 교체했다.
- 검증자 8세대 `01a04067-7ca6-7e00-b02a-fb38c836fd18`는 `MOCKUP-014` 통과 후 9세대로 세대교체했다.
- 이전 세대 작업은 삭제하지 않고 감사와 근거 확인용으로 남긴다.

## 세대교체 기준

- 어느 역할이든 컨텍스트 사용량이 50%에 도달하면 새 세대 작업을 만든다.
- 새 관리자 작업이 지정되면 관리자·기획자·구현자·검증자 4개 작업을 새 세대로 만든다.
- 새 작업은 사이드바에서 사용자가 직접 볼 수 있는 별도 Codex 작업이어야 한다.
- 새 공식 역할 작업은 `create_thread`로 생성된 보이는 Codex 작업이어야 하며, 숨은 multi-agent 하위 에이전트로 대체하지 않는다.
