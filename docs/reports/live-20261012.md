# 10/12 모의 자동매매 2일차: AI가 사고파는 판단까지

- 계좌: KIS 모의투자 (10/8 시작 1,000만 원)
- 기준: 2026-10-12 장 마감 뒤 앱 잔고 화면 (KIS 모의 조회 17:16)
- 사람이 한 일: 아침에 오늘 계획 승인(살 총액 500만 원, AI 매도 허용). 그 뒤 주문·매도 결정에는 손대지 않음
- 장중 바꾼 것: 아래 "그날 고친 것" 참고. 모두 매매 판단이 아니라 시스템 오류 수정

## 2. AI 판단 기록

- 손절선(−7%)까지 간 종목은 없었다. 가장 많이 빠진 현대건설이 장중 −5%대, 종가 −6.09%

## 3. 판단을 돌아보면 (사후 계산, 추정)

- **보유 판단은 오늘 종가로는 틀렸다**: 13:53 판단 시점에 팔았다면 현대건설(−5.0%)·NH(−4.5%)는 종가보다 약 4.4만 원 덜 잃었다 (22주 × 약 1,165원 + 93주 × 약 193원). 하루 결과라 판단 기준이 틀렸다고 단정할 수는 없다
- **막은 추가 매수는 맞았다**: 09:06 셀트리온 7주 추가 매수를 AI가 "관찰"로 막았다. 샀다면 종가 기준 약 2.7만 원 더 잃었다 (7주 × 약 3,800원)
- **오후 신규 매수 0**: 하락장에서 후보 6번을 모두 거절했다. 오른 날에도 너무 조심하는지는 미확인

## 4. 그날 고친 것

| 시각 | 문제 | 조치 |
|---|---|---|
| 장 전~오전 | 팔 종목을 사람이 고르고, 정해진 시각에만 팔게 되어 있었다 | 30분마다 AI가 "곧 떨어질 것 같으면 미리 판다"를 판단, −7%는 AI 없이 손절 |
| 10:00~11:30 | −3% 아래 머문 종목을 11분마다 다시 물어 하루 질문 횟수를 오전에 다 씀 | 지난번보다 1%p 더 떨어졌을 때만 다시 묻고, 아니면 30분 주기 |
| 10:44~13:52 | 서버 하루 분석 한도(20번)가 차서 매도 판단이 약 3시간 멈춤. 앱은 실패를 "AI가 보유 판단"으로 잘못 기록 | 한도 100번(사용자 결정), 한도 실패는 따로 기록하고 질문 횟수에서 뺌 |

가장 큰 교훈: **실패를 판단으로 기록하면 안 된다.** 한도 초과가 "보유"로 보여서 3시간 동안 AI 판단이 꺼진 것을 바로 알아채지 못했다.

## 5. 한계

- 이틀, 4종목이라 전략을 평가할 수 없다. 수십 거래일 기록이 필요하다
- 시장 지수·수급 데이터를 아직 판단에 넣지 않는다. 오늘처럼 시장 전체가 빠지는 날 보유를 고집했을 가능성이 있다
- 매도는 "투자 AI가 매도 제안 + 검증 AI 승인"이 둘 다 필요해서 보수적이다. 오늘 매도 0건이 그 결과인지는 더 봐야 한다

## 6. 보완 (10/12 밤)

두 날의 공통 원인은 **AI가 시장 전체를 못 본 것**이었다. 10/8은 코스피 −2.62% 날 하락 중에 샀고, 10/12는 코스피 −3.65%(4거래일 연속 하락) 날 보유 종목을 계속 들고 있었다.

| 드러난 문제 | 고친 방법 | 확인 |
|---|---|---|
| 시장 지수를 안 봄 | 폰이 KIS 지수 API(현재지수·일자별지수)로 코스피·코스닥 지수, 등락률, 오른/내린 종목 수, 최근 25거래일 종가를 받아 분석 때 보낸다. 서버는 키 없이 받기만 한다 | 모의투자에서 두 API 응답 확인 |
| 며칠 흐름을 모름 | 서버 코드가 1·5·20거래일 등락률과 연속 하락일을 계산해 출처 `market:KOSPI`로 준다. 숫자는 AI가 아니라 코드가 계산 | 10/12 실제 지수로 테스트: "5거래일 −8.42%, 4거래일 연속 하락" |
| 시장 급락을 근거에서 빠뜨림 | 투자 AI 지시: 시장이 크게 빠지면 매수는 관찰, 보유는 줄일지 판단. 검증 AI 지시: 시장 급락을 위험에서 빠뜨리면 지적 | 장 마감 후 실제 앱 분석: 투자 AI가 `market:KOSPI` 출처로 "코스피 −3.65%, 4거래일 연속 하락, 내린 종목 720개"를 근거·위험에 쓰고 **관찰** |
| 시장 급락에도 30분을 기다림 | 코스피 −1.5% 아래(지난 알림보다 1%p 더 빠질 때마다)면 보유 종목 전부를 바로 AI에게 다시 묻는다 | 앱 테스트 |
| 매도는 전부 아니면 0 | 투자 AI가 매도 수량을 전부/절반 중 고르고, 앱은 그만큼만 판다 (1주면 전부) | 앱 테스트 |
| 한도 실패를 "보유 판단"으로 기록 | 실패는 따로 기록하고 질문 횟수에서 뺌, 서버 분석 한도 20 → 100 | 장중 수정 후 14:04부터 정상 판단 |
| 급락 종목을 11분마다 다시 물음 | 지난번보다 1%p 더 빠졌을 때만 다시, 아니면 30분 주기 | 앱 테스트 |

- 매수·매도 기준을 숫자 규칙으로 정하지 않고, **AI가 볼 자료를 늘리고 검증 AI가 확인하게** 했다. 손절(−7%)만 코드 규칙으로 남겼다
- 효과는 아직 모른다. 내일부터 같은 방식으로 모의 자동매매를 이어서 확인한다
